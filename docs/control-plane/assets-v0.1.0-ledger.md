## Frozen contracts

- Assets owns catalog schema, canonical names, geometry, recipes, provenance,
  sprites, checksums, archives, and proof scenarios.
- Goshtoso owns generic sprite rendering and the first catalog-to-Go generator.
- `ahairu` owns project-local brand bindings and public pages.
- `araihu-assets` performs no client source generation in v0.1.0.
- Public paths omit `v11`; catalog metadata retains identity revision 11.
- Tagging, pushes, protected-branch merges, and production deployment require
  the final user checkpoint.
