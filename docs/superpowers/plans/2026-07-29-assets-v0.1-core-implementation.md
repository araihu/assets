# Arai Hû Assets v0.1.0 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the deterministic asset compiler, manifests, catalog, brand/UI sprites, platform packages, export path, and release archives for `v0.1.0`.

**Architecture:** Strict YAML manifests feed small Go packages for SVG validation, brand recipes, pinned UI vendoring, sprites, platform rendering, catalog assembly, confined export, and atomic publication. `cmd/araihu-assets` is a thin dispatcher; `dist/` and release archives remain usable without Go.

**Tech Stack:** Go 1.26.5, `gopkg.in/yaml.v3` v3.0.1, XML/JSON/SHA-256, `os.Root`, librsvg `rsvg-convert` 2.62.1, Make.

## Global Constraints

- Module path: `github.com/araihu/assets`; both `go` and `toolchain` directives use `go1.26.5`.
- `catalog.json` schema is version 1 and records `identityRevision: 11`; public paths omit `v11`.
- No client-language code generation exists in `araihu-assets` v0.1.0.
- Namespaces are `brand` and `ui`; Heroicons uses source `heroicons`, alias `hi`, release `v2.2.0`.
- The UI manifest has an explicit 20–30-file allowlist; normal generation is offline.
- The v0.1.0 UI seed is exactly these 24 `16/solid` Heroicons:
  `academic-cap`, `arrow-down-tray`, `arrow-top-right-on-square`, `bars-3`,
  `check`, `check-circle`, `chevron-down`, `chevron-left`, `chevron-right`,
  `clipboard`, `code-bracket`, `document`, `exclamation-triangle`, `eye`,
  `home`, `information-circle`, `language`, `link`, `magnifying-glass`,
  `moon`, `paint-brush`, `shield-check`, `sun`, and `x-mark`.
- Heroicons tag `v2.2.0` resolves to commit
  `0435d4ca364a608cc75e2f8683d374e55abbae26`.
- Protected multicolor art never inherits `currentColor`; only monochrome/tintable entries may do so.
- Generated files are deterministic, staged, fully validated, then published atomically.
- Git history is the archive; historical numbered concept/proof trees leave the release tree.
